# Rotating Discord Widget — 4 Independent Slots (Shuffle Mode)

Discord profile widget แบบ 4 ช่อง แต่ละช่องมี **รูป + ชื่อ + คำอธิบาย** เป็นของตัวเอง ไม่เกี่ยวข้องกับช่องอื่นเลย แต่ละช่อง**สุ่มลำดับการโชว์เอง** (ไม่เรียงตามลิสต์) โดยรับประกันว่าจะไม่ซ้ำตัวเดิมจนกว่าจะครบทุกตัวในลิสต์ก่อน แล้วค่อยสุ่มรอบใหม่ — หมุนเวียนเปลี่ยนทุก 6 ชั่วโมงอัตโนมัติผ่าน GitHub Actions ไม่ต้องเปิดเครื่องตัวเองทิ้งไว้

## หลักการทำงาน

### 1. ไม่มี state เก็บไว้ที่ไหนเลย — คำนวณจากเวลาปัจจุบันล้วนๆ

```javascript
const block = Math.floor(Date.now() / (6 * 60 * 60 * 1000));
```

`block` คือ "ช่วงเวลาที่เท่าไหร่" นับตั้งแต่ปี 1970 โดยแบ่งเป็นก้อนละ 6 ชม. ค่านี้เปลี่ยนทุก 6 ชม.พอดี และคำนวณจากเวลาจริง ไม่ต้องมี database หรือไฟล์ state ที่ไหนมาเก็บว่า "รอบก่อนหน้าโชว์อะไรไปแล้ว" — รันซ้ำกี่ครั้งในช่วง 6 ชม.เดียวกันก็ได้ผลลัพธ์เดิมเสมอ

### 2. แต่ละช่อง (slot) มีลิสต์ของตัวเอง หมุนอิสระจากช่องอื่น

```javascript
const cycle = Math.floor(block / list.length);   // รอบที่เท่าไหร่ (ครบ 1 รอบ = ผ่านครบทุกตัวในลิสต์นี้)
const position = block % list.length;             // ตำแหน่งภายในรอบนี้
```

เพราะแต่ละช่องมี array แยกกันเองตั้งแต่ต้น (`SLOTS[0]`, `SLOTS[1]`, ...) การหมุนของช่องหนึ่งจึงไม่มีทางไปกระทบหรือไปซ้ำกับช่องอื่นได้เลย ไม่ว่าจะใส่จำนวนรายการเท่ากันหรือไม่ก็ตาม

### 3. สุ่มลำดับแบบ "สับไพ่" (seeded shuffle) — ไม่ซ้ำจนกว่าจะครบรอบ

```javascript
const seed = cycle * 1000003 + slotIdx * 97;
const shuffled = seededShuffle(list, seed);
return shuffled[position];
```

ใช้ตัวสุ่มแบบมีสูตรตายตัว (`mulberry32`) สร้าง seed จาก **เลขรอบ (cycle)** + **หมายเลขช่อง (slotIdx)** แล้วสับลำดับทั้งลิสต์ด้วย seed นั้น (Fisher-Yates shuffle) — คงลำดับเดิมไว้ตลอดทั้งรอบ พอ `position` เดินไปจนครบทุกตำแหน่งในรอบนั้น (เท่ากับครบทุกตัวในลิสต์ไม่ซ้ำกันเลย) ค่า `cycle` จะเปลี่ยน → ได้ seed ใหม่ → สับลำดับใหม่ทั้งหมดอัตโนมัติ

**สิ่งที่การันตีได้:**
- ภายใน 1 รอบ ไม่มีทางซ้ำตัวเดิมเด็ดขาด (เพราะเป็นการสับลำดับ ไม่ใช่จั่วแบบสุ่มอิสระทีละครั้ง)
- ชื่อ, คำอธิบาย, รูป ของตัวละครหนึ่งตัวจะติดกันเป็นก้อนเดียวเสมอ (สุ่ม "ทั้งการ์ด" ไม่ได้แยกสุ่มแต่ละ field)
- แต่ละช่องสับลำดับไม่เหมือนกัน (เพราะ seed ผูกกับ `slotIdx` ด้วย)

### 4. ถ้าปิด workflow ชั่วคราวแล้วเปิดใหม่

ระบบไม่ได้ "หยุดค้าง" รอ แล้วมาต่อจากจุดเดิม — เพราะคำนวณจากเวลาปัจจุบันจริงทุกครั้ง ตัวที่ควรได้คิวโชว์ในช่วงที่ปิดอยู่จะถูก**ข้ามไปเงียบๆ** (ไม่ error ไม่ค้าง) พอเปิดกลับมาระบบจะกระโดดไปคำนวณตำแหน่งปัจจุบันตามเวลาจริงทันที ตัวที่ถูกข้ามจะไม่หายไปถาวร แค่รอบถัดไปที่วนมาถึงตำแหน่งเดิมก็จะกลับมาโชว์ตามปกติ

## Setup

### ส่วนที่ 1 — Discord Application + Widget

ใช้สคริปต์ของ aamiaa ผ่าน DevTools console ในหน้า `discord.com/developers/applications` (`Ctrl+Shift+I` → Console → พิมพ์ `allow pasting` ถ้าถูกถาม แล้ววางสคริปต์จาก [aamiaa's WidgetCreator gist](https://gist.github.com/aamiaa/7cdd590e3949cd654758bc90bcb4710b)) จะได้ **Application ID**, **Bot Token**, และเอา **Discord User ID** ของคุณเอง (Settings → Advanced → เปิด Developer Mode → คลิกขวาชื่อตัวเอง → Copy User ID)

### ส่วนที่ 2 — Deploy ขึ้น GitHub

1. สร้าง repo ใหม่ (private) อัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ (ให้แน่ใจว่ามี `.github/workflows/update.yml` อยู่ในตำแหน่งที่ถูกต้อง)
2. **Settings → Secrets and variables → Actions** เพิ่ม 3 secret:

   | Secret | ค่า |
   |---|---|
   | `DISCORD_CLIENT_ID` | Application ID |
   | `DISCORD_USER_ID` | Discord User ID ของคุณ |
   | `DISCORD_BOT_TOKEN` | Bot Token |

3. แท็บ **Actions** → เลือก workflow "Update Rotating Discord Widget" → **Run workflow** รันครั้งแรก (การรันครั้งแรกเป็นตัวจดทะเบียนชื่อ field ให้ Discord รู้จักด้วย)

### ส่วนที่ 3 — ผูก field ใน Widget Editor

กลับไปหน้า Widget Editor (Application → Games → Widget) ตั้ง Value Type เป็น **User Data** แล้วพิมพ์ชื่อ field ตามตาราง (ตัวพิมพ์เล็ก-ใหญ่ต้องตรงเป๊ะ) — รวมทั้งหมด 12 field (4 ช่อง × 3 field):

| ช่อง | field รูป | field ชื่อ | field คำอธิบาย |
|---|---|---|---|
| ช่องที่ 1 | `slot1_image` | `slot1_name` | `slot1_desc` |
| ช่องที่ 2 | `slot2_image` | `slot2_name` | `slot2_desc` |
| ช่องที่ 3 | `slot3_image` | `slot3_name` | `slot3_desc` |
| ช่องที่ 4 | `slot4_image` | `slot4_name` | `slot4_desc` |

## การแก้ไข/เพิ่มรายการ

เปิดไฟล์ `widget.js` แก้ในตัวแปร `SLOTS` — เป็น array ของ 4 array ย่อย (หนึ่งอันต่อหนึ่งช่อง):

```javascript
const SLOTS = [
    // ---- ช่องที่ 1 ----
    [
        { name: "...", description: "...", image: "https://..." },
        { name: "...", description: "...", image: "https://..." },
        // ใส่กี่รายการก็ได้ ไม่จำกัด
    ],
    // ---- ช่องที่ 2 ----
    [ ... ],
    // ---- ช่องที่ 3 ----
    [ ... ],
    // ---- ช่องที่ 4 ----
    [ ... ],
];
```

**กฎที่ต้องรู้:**
- แต่ละช่องต้องมี**อย่างน้อย 1 รายการ** ไม่งั้น script จะ error ตั้งแต่ต้น (กันไว้ไม่ให้ยิงข้อมูลผิดขึ้น Discord)
- ใส่จำนวนรายการต่อช่องได้**ไม่จำกัด** เพราะแต่ละรอบส่งแค่ 1 ตัวต่อช่องขึ้น Discord (ไม่เกี่ยวกับลิมิต 30 field ของ Discord) — แต่ยิ่งใส่เยอะ ยิ่งวนกลับมาโชว์ตัวเดิมช้าลง (จำนวนตัว × 6 ชม. = เวลาที่วนครบ 1 รอบ)
- `image` ต้องเป็น**ลิงก์ตรงถึงไฟล์รูป** (raw link) ไม่ใช่ลิงก์หน้าเว็บ — ถ้าใช้ GIF บางเว็บ (เช่น Tenor) อาจใช้งานไม่ได้เพราะ hotlink/redirect protection แนะนำใช้ Giphy หรือโฮสต์ผ่าน GitHub/Imgur โดยตรงแทน
- แก้เสร็จ commit ขึ้น GitHub ระบบหมุนเวียนอัตโนมัติทุก 6 ชม.

## ปรับความถี่การหมุนเวียน

ถ้าอยากเปลี่ยนจาก 6 ชม. เป็นค่าอื่น ต้องแก้ **2 จุดให้ตรงกัน**:

1. `widget.js`: `const SIX_HOURS_MS = 6 * 60 * 60 * 1000;`
2. `.github/workflows/update.yml`: `cron: "0 */6 * * *"`

## ปรับจำนวนช่อง (ถ้าไม่ใช่ 4)

เพิ่ม/ลบ array ย่อยใน `SLOTS` ได้ตามต้องการ ระบบจะสร้าง field `slot1_...` ถึง `slotN_...` ตามจำนวนช่องที่มีอัตโนมัติ (แต่ต้องไปเพิ่ม/ลบ field ในหน้า Widget Editor ให้ตรงกันเองด้วย และรวมทั้งหมดห้ามเกิน 30 field ตามลิมิตของ Discord — ที่ 4 ช่องตอนนี้ใช้ไป 12 field ยังเหลือพื้นที่อีกเยอะ)

## Troubleshooting

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Run fails: `ช่องที่ N ไม่มีรายการเลย` | ลิสต์ของช่องนั้นใน `SLOTS` ว่างเปล่า ใส่อย่างน้อย 1 รายการ |
| Run fails: `Invalid Form Body (50035)` | field ทั้งหมดใน 1 รอบเกิน 30 รายการ — ลดจำนวนช่อง หรือลด field ต่อช่อง |
| Widget โชว์ placeholder/fallback บางช่อง | ชื่อ field ใน editor สะกดไม่ตรงกับใน `widget.js` (ตัวพิมพ์เล็ก-ใหญ่มีผล) |
| รูปไม่ขึ้น (โดยเฉพาะ GIF) | ลิงก์ `image` ไม่ใช่ลิงก์ตรงถึงไฟล์รูป, เว็บที่ฝากรูปบล็อก hotlink, หรือไฟล์ใหญ่เกินไป — ลองใช้ Giphy หรือรูปนิ่ง PNG/JPG แทน |
| Widget ค้าง ไม่อัปเดต | Discord client cache ไว้ กด Ctrl+R รีเฟรช |
| ลำดับที่โชว์ดูไม่สุ่มเลย เรียงตามลิสต์เป๊ะ | เช็คว่าโค้ดใน `widget.js` มีฟังก์ชัน `seededShuffle`/`mulberry32` อยู่จริง (ถ้าไฟล์เก่าอาจยังเป็นเวอร์ชันก่อนเพิ่มระบบสุ่ม) |
